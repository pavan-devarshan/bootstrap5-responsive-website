# 🚀 Bootstrap 5 Responsive Website

A modern, responsive, multi-page website built using **Bootstrap 5**, created as part of an internship assignment to explore Bootstrap components and design clean, user-friendly layouts.

---

## 📌 Project Overview

This project focuses on **remixing Bootstrap 5 components** into a cohesive and visually appealing website.  
The goal was to practice real-world frontend skills such as layout composition, responsiveness, UI consistency, and clean project structure.

The website consists of **three separate pages**:
- Home
- About
- Contact

All pages share a consistent design system and styling.

---

## ✨ Key Features

- Responsive Navbar (Bootstrap 5)
- Hero Section with Call-to-Action
- Bootstrap Carousel
- Modal Popup
- Dark / Light Theme Toggle (Bootstrap 5 theme system)
- Reusable Card Components
- Responsive Grid Layout
- Clean and modern UI/UX
- Mobile-first design

---

## 🛠️ Technologies Used
